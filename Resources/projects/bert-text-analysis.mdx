## Overview

A single BERT encoder fine-tuned to solve three NLP tasks at once: classifying sentiment, detecting paraphrases, and computing semantic similarity between sentence pairs.

## Approach

- Started from a pretrained BERT checkpoint and added task-specific classification heads.
- Combined all three objectives into one training loop with a **custom task-weighted loss** so no single task dominated the gradient updates.
- Shared the transformer backbone across tasks to enable knowledge transfer between sentiment and semantic understanding.

## Results

- Paraphrase detection reached **82% accuracy** on the evaluation set.
- The multi-task setup converged faster than training each task separately, since the shared encoder learned richer, more general representations.

## Key Takeaways

- Designing weighted multi-task losses requires careful balancing of loss scales across heads.
- Multi-task fine-tuning is an efficient way to reuse one model for several production NLP needs.
